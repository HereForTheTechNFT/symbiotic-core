# Symbiotic : introduction

Symbiotic est une couche de shared security flexible et permissionless. Les contrats coordonnent le collateral, les vaults, les opérateurs, les réseaux et les règles de slashing.

Un déposant conserve son actif dans un vault, tandis que des réseaux sélectionnent des opérateurs et des garanties pour sécuriser leurs services. Cette séparation permet plusieurs modèles de délégation.

Ce parcours lit le dépôt forké. Aucune installation, compilation ou exécution n’a été effectuée.
