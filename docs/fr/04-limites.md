# Symbiotic : limites et périmètre

Symbiotic ne définit pas à lui seul la sécurité économique complète d’un réseau : les middleware, les opérateurs, les resolvers et les paramètres de vault doivent être correctement configurés. Une mauvaise sélection peut concentrer le risque ou réduire la disponibilité.

Le slashing, les délais de retrait, les limites d’adapter et les frais exigent une lecture conjointe du code et des déploiements. Les interfaces donnent de la flexibilité, mais déplacent une partie du risque vers l’intégration.

Ce parcours couvre les contrats cœur, les rôles et les flux principaux ; il ne remplace pas un audit. La suite de tests du dépôt est la référence pour approfondir, sans exécution ici.
