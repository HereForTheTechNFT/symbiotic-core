# Symbiotic : architecture

Les vaults assurent la comptabilité, la délégation et la distribution des récompenses. Les operators fournissent l’infrastructure ; les networks expriment les besoins de sécurité ; les middleware consomment les garanties selon leurs propres règles.

Les resolvers peuvent intervenir dans la gestion des incidents de slashing. Les interfaces et modules séparent les dépôts des décisions propres à chaque réseau, ce qui favorise la composition.

La sécurité découle donc de contrats de base, de configurations opt-in et de relations explicites entre participants.
